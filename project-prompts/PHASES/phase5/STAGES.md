
# Phase 2 — Financial Management Expansion

## Goal
Extend the MVP with comprehensive finance management, richer user experience, and persistent preferences.

## Scope
- Income management
  - Add, edit, delete income items
  - Income list screen and filtering
- Budget management
  - Add, edit, delete budgets
  - Monthly budget tracking and alerts
- Category management
  - Add and manage categories
  - Use categories for expenses and income
- Dashboard and analytics
  - Aggregated totals for expense, income, and budget
  - Analytics charts and category breakdowns
- Theme and preferences
  - Dark/light/system theme modes
  - Persist theme selection across launches
- UI quality
  - Empty-state handling for lists
  - User-friendly validation and error feedback
  - Responsive navigation across tabs

## Deliverables
- Income and budget screens
- Category workflow integrated with transactions
- Dashboard summary and analytics views
- Theme persistence and polished UI

## Exclusions
- Backend API sync beyond existing local fallback
- Production-grade network error retry logic
- EAS production build verification
