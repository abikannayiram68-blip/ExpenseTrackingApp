# Phase 7: Budget Management

Phase 7 adds budget planning and tracking features.

## Goals
- Create budget categories or targets.
- Track spending against budgets.
- Show budget status and limits.

## Tasks
- Create `BudgetListScreen.tsx` that lists budgets.
- Create `AddBudgetScreen.tsx` with fields for budget name, amount, and period.
- Add budget progress indicators.
- Link budgets to expense categories if possible.
- Show remaining budget values on the dashboard.

## Expected Results
- Users can create and view budgets.
- Budget items display current amount and limit.
- Budget tracking helps users control spending.

## Notes
- Start with a simple budget model.
- Expand later with notifications or alerts.
