# Phase 5: Expense Management

Phase 5 adds full expense tracking screens and user actions.

## Goals
- Allow users to add, view, edit, and delete expenses.
- Provide a list of expense records.
- Add forms for expense details.

## Tasks
- Create `ExpenseListScreen.tsx` to display expense items.
- Create `AddExpenseScreen.tsx` with fields for amount, category, date, and note.
- Add buttons to save or cancel expense creation.
- Add edit and delete actions for each expense item.
- Use local state or a simple list to store expenses.

## Expected Results
- Users can manage their expense entries.
- The expense list updates when items are added or changed.
- The add/edit expense experience is clear and easy.

## Notes
- Start with local mock data if no backend exists yet.
- Leave room for backend integration in a later phase.
