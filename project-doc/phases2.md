# Phase 2: Authentication Screens

Phase 2 adds the screens needed to log in and register users.

## Goals
- Create authentication screens.
- Build UI for login, registration, and password recovery.
- Add form validation and user feedback.

## Tasks
- Create `LoginScreen.tsx` with email and password fields.
- Create `RegisterScreen.tsx` with name, email, password, and confirm password fields.
- Create `ForgotPasswordScreen.tsx` with email input.
- Add client-side validation for required fields and password match.
- Show error messages when input is invalid.
- Add buttons for submission and navigation between auth screens.

## Expected Results
- Users can navigate between login, register, and forgot password.
- The forms look good on mobile screens.
- Basic validation prevents empty or incorrect input.

## Notes
- Do not connect to backend yet.
- Keep auth flow ready for integration in later phases.
