# Phase 6: Income Management

Phase 6 adds income tracking screens for salary, freelance, and other income.

## Goals
- Let users add, view, edit, and delete income entries.
- Show a list of income records.
- Keep income separate from expenses.

## Tasks
- Create `IncomeListScreen.tsx` to show income items.
- Create `AddIncomeScreen.tsx` with fields for amount, source, date, and notes.
- Add save and cancel buttons.
- Add edit and delete functions for income records.
- Display income totals on the dashboard.

## Expected Results
- Users can track incoming money.
- Income entries appear in a list and can be updated.
- Income data is clearly separated from expenses.

## Notes
- Use placeholder data first if needed.
- Integrate income with budget and analytics later.
