# Phase 4: Dashboard UI

Phase 4 builds the home dashboard where users first land after login.

## Goals
- Create a dashboard screen with summaries.
- Show total expenses, income, and budget status.
- Add visual elements like cards and charts.

## Tasks
- Build `DashboardScreen.tsx` with a welcome header.
- Add summary cards for total spent, total income, and remaining budget.
- Add a section for recent transactions or quick actions.
- If possible, add a simple chart or analytics preview.
- Create reusable card components in `src/components/cards`.

## Expected Results
- The dashboard feels informative and modern.
- Users can see their key financial totals at a glance.
- The dashboard layout works on different device sizes.

## Notes
- The data can be static or mocked in this phase.
- Focus on layout and clear information display.
