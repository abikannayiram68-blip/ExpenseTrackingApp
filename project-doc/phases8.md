# Phase 8: Category Management

Phase 8 adds categories for organizing expenses and income.

## Goals
- Create categories for expenses and income types.
- Let users add and manage categories.
- Use categories for reports and filters.

## Tasks
- Create `CategoryListScreen.tsx` to show category items.
- Create `AddCategoryScreen.tsx` with category name, type, and color/icon.
- Add edit and delete actions for categories.
- Allow selecting categories when adding expenses or income.
- Use categories in filters for list screens.

## Expected Results
- Users can define custom categories.
- Categories are available when creating entries.
- Reports can later use categories to group data.

## Notes
- Keep category creation simple at first.
- Add icons or colors later for a better experience.
