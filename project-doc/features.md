# Features

This app includes many useful features for tracking personal finance.

## Main Features

- User authentication with login and registration.
- Secure token storage for auto-login.
- Protected app screens that require user login.
- Add, edit, and delete expenses.
- Add, edit, and delete income entries.
- Create and manage budgets.
- Create and manage expense categories.
- View detailed lists for expenses, income, budgets, and categories.

## Dashboard and Analytics

- Dashboard shows a quick summary of money in and money out.
- Charts and graphs for spending analysis.
- Summary cards for totals and trends.

## UI and Experience

- Clean mobile interface built for Android and iOS.
- Reusable buttons and input fields.
- A theme system for consistent colors and fonts.
- Responsive navigation with bottom tabs and stacks.

## Developer Features

- TypeScript types for safer code.
- Axios service layer for network calls.
- Context API for app-wide state management.
- Expo EAS build configuration for APK creation.
- Local database schema file for backend support.
