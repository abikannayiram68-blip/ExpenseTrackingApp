# Phase 1: Project Setup

In Phase 1, we build the basic foundation for the app.

## Goals
- Create the Expo project.
- Set up TypeScript.
- Install core packages for navigation, UI, and data fetching.
- Build the folder structure and core app files.

## Tasks
- Initialize Expo with `expo init`.
- Add `App.tsx` and start the app entry flow.
- Configure `tsconfig.json` for TypeScript support.
- Add `app.json` and `eas.json` for Expo configuration and build settings.
- Create main folders: `src/navigation`, `src/screens`, `src/components`, `src/context`, `src/services`, `src/constants`, and `src/utils`.
- Install packages like `react-navigation`, `axios`, `react-native-paper`, and `expo-secure-store`.

## Expected Results
- The app starts successfully in Expo.
- Basic navigation structure exists.
- Project files are organized and ready for development.

## Notes
- This phase is mostly setup work.
- Keep the code simple and clear.
- Avoid adding full screens or backend logic yet.
