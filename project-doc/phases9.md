# Phase 9: Analytics and Reports

Phase 9 adds charts and reports so users can understand their money habits.

## Goals
- Show spending and income analytics.
- Add charts for categories, time, and budget performance.
- Provide easy-to-read reports.

## Tasks
- Create `AnalyticsScreen.tsx` with charts and summary cards.
- Add a line chart or bar chart for monthly spending.
- Add category breakdown summary.
- Add high-level totals for income vs expenses.
- Create report sections for last 7 days, month, and year.

## Expected Results
- Users can see their financial trends.
- Charts help users compare different periods.
- Analytics feel useful and not cluttered.

## Notes
- Use static or mock data if backend is unavailable.
- Add real analytics once data flows from services.
